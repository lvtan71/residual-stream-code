# The Notebook Assistant, End to End: the full code

The scripts behind [The Notebook Assistant, End to End](https://residual-stream.lvtan71.workers.dev/posts/notebook-assistant-end-to-end/). Each `.out` file is what its script printed for the post.

| Script | What it does | Needs |
| --- | --- | --- |
| `notebook.py` | The assistant: a semantic cache, hybrid retrieval (BM25 and MiniLM over 100-word chunks, fused by rank), a cross-encoder reranker, a prompt that fences the passages as data, Qwen2.5-3B-Instruct answering with citations, and a citation check; plus the LLM judge. A helper, no output. | Downloads Qwen2.5-3B-Instruct (about 6 GB), all-MiniLM-L6-v2 and ms-marco-MiniLM-L6-v2 at pinned revisions |
| `scorecard.py` | Traces one question through every stage, then runs the 150 test questions (retrieval, citations, the judge, the check, time and tokens per answer), 30 rewordings for the cache, 15 questions the blog doesn't answer, and a poisoned post planted in the index. Saves every answer to `answers.json`. | GPU, about 18 minutes |
| `rescore.py` | Rescores `answers.json` with stricter rules: refusals, citations on answers only, how many answer sentences any chunk holds, and whether each cache hit matched its own question. No model calls but the embedder. | CPU, under a minute |
| `cost_sketch.py` | The cost sketch of AI Engineering, from the Inside (an 8B model on one H100), with the prompt and answer lengths measured here. | Python, instant |

`blog-6698eca.tar.gz` links to `../../data/blog-6698eca.tar.gz`, the blog's posts at commit `6698eca` (`content/posts`). `common.py`, which turns the posts into clean text, is a copy of the helper from [Building RAG](https://residual-stream.lvtan71.workers.dev/posts/building-rag-chunking-hyde-and-caching/). `gen.json` links to `../../data/gen.json`, that post's 150 test questions with their source sentences and rewordings. The file the post used is lost; this one was regenerated by that post's code, so the scorecard's counts differ from the post's.

Run times are estimates from the post's 19 minutes in total. The outputs here came from an Apple M4 laptop with torch 2.14.1 and transformers 5.18.

```bash
pip install "numpy==2.*" "torch==2.14.*" "transformers==5.18.*" sentence-transformers huggingface_hub
tar xzf blog-6698eca.tar.gz
python scorecard.py
python rescore.py
python cost_sketch.py
```
